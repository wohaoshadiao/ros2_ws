# 🚀 ROS 2 Workspace with Docker Support

本仓库用于存放基于 **ROS 2 Humble** 的工作空间，并提供了一个用于快速构建和部署的 **Dockerfile**，方便在不同设备（x86/ARM）上开发和运行。

## 🧩 功能说明

- 包含多个自定义 ROS 2 功能包（如避障、雷达处理等）
- `vision_tracking`：图像识别与追踪
- 提供 Docker 环境，便于快速部署至本地/远程设备
- 支持跨架构构建（x86 构建 ARM 镜像）
